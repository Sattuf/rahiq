# الأمان (Security)

المرجع: OWASP Top 10 و OWASP API Security Top 10.

## 1. الحسابات
- ASP.NET Core Identity. تسجيل الدخول بالبريد وكلمة المرور، أو **رابط سحري / رمز لمرة واحدة بالبريد أو SMS** (أسهل لزبائن المتجر من كلمات المرور).
- كلمات المرور: 10 أحرف على الأقل، فحص ضد القوائم المسربة.
- قفل مؤقت متصاعد بعد المحاولات الفاشلة، ورسائل موحدة لا تكشف وجود البريد.
- **2FA (TOTP) إلزامي لكل حسابات لوحة الإدارة.**

## 2. الجلسات: نمط BFF
- Next.js يحمل الجلسة في كوكي httpOnly، Secure، SameSite=Lax، مشفرة. الرموز لا تصل إلى JavaScript المتصفح.
- Access token قصير (15 دقيقة) و Refresh token مُدوّر مع كشف إعادة الاستخدام، مخزن مجزّأً.
- حماية CSRF على كل طلبات التغيير.

## 3. التفويض
- أدوار الإدارة: Owner، Manager، Content، Fulfillment، Support، مبنية على صلاحيات دقيقة (`orders.refund`، `products.publish`، `prices.edit`...).
- **الاسترداد وتعديل الأسعار صلاحيات منفصلة ومسجلة.** الاسترداد فوق مبلغ معين يحتاج موافقة Owner.
- الزبون يرى طلباته فقط: كل استعلام بـ `customer_id` من الجلسة. **صفحة تتبع الطلب للضيف** تتطلب رقم الطلب + البريد معًا، وتُحد بمعدل.
- صفحة الدفعة العامة (QR) بـ `public_token` عشوائي، لا بمعرف متسلسل، وتعرض بيانات الدفعة فقط، لا أي بيانات طلبات.

## 4. الدفع (القانون 7)
- نموذج الدفع المستضاف لدى المزود (أو حقول مستضافة iframe). بيانات البطاقة لا تمر بخوادمنا، فيبقى نطاق PCI DSS في أدنى مستوياته (SAQ A).
- 3D Secure دائمًا.
- التحقق من توقيع كل webhook، ورفض أي إشعار غير موقع أو بمبلغ غير مطابق.
- مفاتيح المزود في خزنة أسرار، مع مفاتيح منفصلة للـ Sandbox والإنتاج.

## 5. الاحتيال وإساءة الاستخدام
- Rate limiting (Redis): تسجيل الدخول، طلب الرمز، إضافة القسائم (منع تخمين الأكواد: 10 محاولات في الساعة)، الدفع، تتبع الطلب.
- **Cloudflare Turnstile** على: التسجيل، الدفع عند الاستلام، نموذج التواصل.
- إشارات احتيال بسيطة تُعلّم الطلب للمراجعة اليدوية: عدة محاولات بطاقات فاشلة من نفس الجلسة، عنوان شحن بعيد عن الفوترة مع طلب كبير لأول مرة، استخدام قسيمة ترحيب بحسابات متعددة من نفس الجهاز أو العنوان.
- Cloudflare WAF وحماية البوتات.

## 6. الإدارة
- لوحة الإدارة تحت `/admin` خلف 2FA، ويمكن تقييدها إضافيًا بـ Cloudflare Access.
- سجل تدقيق غير قابل للتعديل: تغيير الأسعار، الاسترداد، تعديل المخزون، نشر المنتجات، تغيير الصلاحيات، تجاوز تحذير الكلمات الممنوعة.

## 7. الملفات والمحتوى
- صور المنتجات وتقارير المختبر ترفعها الإدارة فقط: Presigned URL إلى حاوية حجر، فحص البايتات السحرية، إعادة ترميز الصور وحذف البيانات الوصفية، و PDF يُفحص ويُقدم من نطاق منفصل للأصول.
- محتوى الإدارة (القصص) يُحرر بمحرر منظم (Markdown أو كتل)، ويُنظف من HTML قبل العرض.
- رسائل الهدايا من الزبائن: نص خام يُهرّب عند العرض والطباعة، بحد طول.

## 8. الرؤوس والنقل
HTTPS و HSTS، CSP صارمة مع Nonce (مع السماح بنطاقات مزود الدفع اللازمة فقط)، `frame-ancestors 'none'`، `nosniff`، `Referrer-Policy`، `Permissions-Policy`. CORS على الـ API لأصل Next.js فقط.

## 9. الأسرار والبيانات
- لا أسرار في المستودع (gitleaks في CI). خزنة للإنتاج.
- Data Protection keys مشتركة ومستمرة.
- تشفير النسخ الاحتياطية.
- السجلات لا تحتوي البريد الكامل أو الهاتف أو العنوان (تقنيع)، ولا الرموز.
- سياسة احتفاظ: الطلبات حسب المدة المحاسبية القانونية، وبيانات التسويق حتى سحب الموافقة، والسلال المهجورة 30 يومًا.
- حق الزبون في تنزيل بياناته وحذف حسابه (مع الاحتفاظ بما يفرضه القانون المحاسبي، مجهّلًا حيث أمكن).
