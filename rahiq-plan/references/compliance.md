# الامتثال القانوني والتنظيمي (Compliance)

> **تنبيه مهم:** هذا الملف خريطة لما يجب التحقق منه، مكتوبة على افتراض أن المتجر في تركيا ويبيع داخلها. القوانين تتغير، وتفاصيلها تختلف حسب نوع النشاط وحجمه. **لا يغني عن محاسب قانوني (Mali Müşavir) ومحامٍ.** اعرض عليهما هذا الملف في المرحلة 1، ودع كل بند يُعلَّم بتأكيدهما.

## 1. لماذا يأتي هذا قبل التصميم والكود؟

لأن ثلاثة من قرارات المنتج تتوقف عليه:
1. **خلطات العسل:** إضافة أعشاب أو مستخلصات للعسل وتقديمها بفوائد صحية قد يحوّل المنتج قانونيًا من "غذاء" إلى **"مكمل غذائي" (Takviye Edici Gıda)**، وهذا يتطلب موافقة مسبقة من وزارة الزراعة والغابات. تسمية المنتج وطريقة وصفه تحدد تصنيفه.
2. **العطور:** بيعها يتطلب إشعارًا في نظام تتبع المنتجات لدى هيئة الأدوية (TİTCK) عبر **ÜTS**، وتقرير سلامة، وشخصًا مسؤولًا، وملصقًا بمكونات INCI. إن كنت تعبئ أو تركب عطورك بنفسك، فهناك متطلبات تصنيع إضافية.
3. **حق الإرجاع:** له استثناءات تخص الأغذية سريعة التلف ومنتجات التجميل المفتوحة، وهذا يغير سياسة الإرجاع وتصميم التغليف (ختم يثبت عدم الفتح).

## 2. الادعاءات الصحية (الأخطر)

الأغذية لا يجوز أن تُنسب إليها خاصية الوقاية من مرض أو علاجه أو شفائه. والادعاءات الصحية المسموحة محدودة بقائمة معتمدة وشروط. هيئة الإعلانات في وزارة التجارة (Reklam Kurulu) تفرض غرامات على الإعلانات الصحية المضللة، والأغذية والعسل من أكثر المجالات التي تُراقب.

| ممنوع | البديل المقترح |
|---|---|
| "خلطة طبية" | "خلطة عسل" / "عسل بالحبة السوداء والزنجبيل" |
| "يعالج السعال والتهاب الحلق" | "خلطة تقليدية تُحضّر في الشتاء منذ أجيال" |
| "يقوي المناعة" | (لا بديل صحي. اوصف الطعم والمكونات) |
| "مفيد لمرضى السكري" | (ممنوع، والعكس هو التحذير الصحيح) |
| "شفاء" / "şifalı" | "طبيعي" فقط إن كان صحيحًا ومثبتًا |
| "أفضل عسل في العالم" | "عسل كستناء من دفعة سبتمبر، محلَّل مخبريًا" |

**التنفيذ في الكود (القانون 1):**
- قائمة كلمات ممنوعة بثلاث لغات (`يعالج، يشفي، علاج، دواء، شفاء، مناعة، tedavi, şifa, şifalı, iyileştirir, bağışıklık, cure, heal, treat, remedy, immune`...) تُفحص عند حفظ أي منتج أو قصة أو قسيمة. التطابق = تحذير يمنع النشر حتى يوافق مدير المتجر صراحة ويُسجل ذلك.
- القائمة تُراجع مع المحامي وتُحدث.

## 3. قائمة الامتثال (المرحلة 1)

### الكيان التجاري والضرائب
- [ ] شكل الشركة المناسب (فردية أو محدودة) مع المحاسب.
- [ ] مزود **الفاتورة الإلكترونية** (e-Arşiv / e-Fatura عبر مزود تكامل معتمد) مع واجهة API لربطه بالمتجر.
- [ ] نسب ضريبة القيمة المضافة (KDV) لكل فئة منتج (الأغذية ومستحضرات التجميل قد تختلف نسبها). تُخزَّن كبيانات لا كأرقام في الكود.

### الغذاء (العسل والمكسرات والخلطات)
- [ ] **شهادة تسجيل منشأة غذائية** (Gıda İşletmesi Kayıt Belgesi) لمكان التعبئة والتخزين، أو التأكد من أن المورد مسجل إن كان هو من يعبئ.
- [ ] مطابقة العسل لتعليمات العسل في الكودكس الغذائي التركي (Türk Gıda Kodeksi Bal Tebliği).
- [ ] ملصق مطابق للائحة الملصقات الغذائية: الاسم، المكونات، مسببات الحساسية بخط بارز، الوزن الصافي، تاريخ الصلاحية، رقم الدفعة، المنتِج أو المعبئ، بلد المنشأ، وشروط الحفظ.
- [ ] **تصنيف الخلطات:** هل هي غذاء عادي أم مكمل غذائي؟ قرار بالمكونات والنسب وطريقة التقديم، مع المحامي أو مستشار غذائي. إن كانت مكملًا: موافقة الوزارة قبل البيع.
- [ ] تقارير تحليل مخبري لكل دفعة عسل من مختبر معتمد (مستحسن بقوة: الثقة، وحماية قانونية عند النزاع).
- [ ] تحذير الرضع دون 12 شهرًا على كل منتج عسل (توصية صحية عالمية بسبب خطر التسمم الوشيقي عند الرضع).

### مستحضرات التجميل (العطور)
- [ ] إشعار المنتج في **ÜTS** قبل البيع.
- [ ] **الشخص المسؤول** (Sorumlu Kişi) وتقرير سلامة المنتج (Güvenlik Değerlendirmesi) لكل عطر.
- [ ] ملصق: المكونات INCI، مسببات الحساسية العطرية فوق الحدود، الحجم، رقم الدفعة، التحذيرات، الجهة المسؤولة.
- [ ] إن كنت تبيع علامات عالمية: مصدر أصلي موثق بفواتير. **ممنوع بيع "عطور مستوحاة من" علامة مشهورة باسمها** (مخالفة علامات تجارية)، ولا تقسيم قوارير علامات أخرى إلى عيّنات تحمل اسمها دون التحقق القانوني.
- [ ] إن كنت تركب عطورك: متطلبات التصنيع لدى TİTCK.

### التجارة الإلكترونية وحماية المستهلك
- [ ] التسجيل في **سجل مقدمي خدمات التجارة الإلكترونية (ETBİS)** وعرض المعلومات المطلوبة في الموقع.
- [ ] **نموذج المعلومات المسبقة** (Ön Bilgilendirme Formu) و**عقد البيع عن بعد** (Mesafeli Satış Sözleşmesi) يُولَّدان لكل طلب بمحتواه الفعلي، ويقبلهما الزبون قبل الدفع، ويُرسلان له ويُحفظان.
- [ ] **حق الانسحاب (14 يومًا)** واستثناءاته: الأغذية سريعة التلف أو القريبة الانتهاء، ومنتجات التجميل التي فُتح ختمها الصحي. **صمم ختمًا يثبت عدم الفتح** (غلاف شفاف أو ملصق أمان) لتطبيق الاستثناء بعدل.
- [ ] **عرض الخصومات:** القواعد التركية تشترط أن يكون "السعر السابق" المعروض بجانب سعر الخصم هو أدنى سعر خلال فترة سابقة محددة (30 يومًا). الكود يخزن تاريخ الأسعار ويحسب ذلك آليًا، ولا يُسمح بإدخال "السعر قبل الخصم" يدويًا.
- [ ] الأسعار شاملة الضريبة، وتكلفة الشحن معلنة قبل الدفع.

### الاتصالات التسويقية والخصوصية
- [ ] **نظام إدارة الرسائل التجارية (İYS):** التسجيل، وأي رسالة تسويقية (SMS أو بريد) تتطلب موافقة مسجلة فيه. رسائل الطلب والشحن (معاملاتية) لا تتطلبها.
- [ ] **KVKK:** نص الإعلام (Aydınlatma Metni)، موافقة صريحة منفصلة للتسويق، سياسة الكوكيز مع موافقة فعلية على الكوكيز غير الضرورية، حق الحذف والاطلاع. التحقق من لزوم التسجيل في VERBİS.
- [ ] نقل البيانات للخارج (خوادم، أدوات تحليل، بريد): مراجعة مع المحامي.

### الدفع والشحن
- [ ] عقد مع مزود دفع مرخص (iyzico أو PayTR أو بنك) يدعم 3D Secure والتقسيط.
- [ ] شروط شركات الشحن للسوائل والمواد القابلة للاشتعال (العطور تحتوي كحولًا). الشحن البري الداخلي عادة ممكن بشروط تغليف، والجوي والدولي مقيد جدًا.

## 4. أين يظهر كل هذا في النظام؟

| المتطلب | مكانه |
|---|---|
| التحذيرات ومسببات الحساسية | حقول منظمة في المنتج، مكوّن عرض ثابت، إلزامية حسب النوع |
| الكلمات الممنوعة | مدقق عند الحفظ، مع سجل موافقات |
| الدفعة وتاريخ الانتهاء | كيان Batch، FEFO، منع البيع قرب الانتهاء |
| العقود | مولّد مستندات من قوالب + بيانات الطلب، نسخة PDF محفوظة بـ Hash |
| سعر الخصم | جدول تاريخ الأسعار، حساب أدنى سعر آليًا |
| الفاتورة الإلكترونية | تكامل مع مزود e-Arşiv عند `PaymentSucceeded` أو عند الشحن (حسب رأي المحاسب) |
| الموافقات التسويقية | حقول موافقة بتاريخ ومصدر، مزامنة مع İYS |
| ETBİS والمعلومات التجارية | تذييل الموقع وصفحة "من نحن" |
