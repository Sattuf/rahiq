# رحيق: حزمة خطة متجر العطور والعسل

متجر إلكتروني بقسمين تحت علامة واحدة: **العطور** و**العسل** (العسل الخام، المكسرات بالعسل، خلطات العسل). خلفية ASP.NET Core بـ Clean Architecture، وواجهة Next.js بتجربة "الضوء عبر السائل"، ودفع إلكتروني وامتثال قانوني.

## ترتيب القراءة
1. `PLAN.md`
2. `references/decisions-adr.md` (خاصة ADR-000)
3. `references/compliance.md` قبل أي نص منتج
4. `references/brand-identity.md`، ثم الباقي حسب المرحلة.

## الاستخدام مع Claude Code

> اقرأ `rahiq-plan/PLAN.md` كاملًا، ثم كل ملفات `references/`. لا تكتب كودًا قبل ذلك. ابدأ بالمرحلة 0، وتوقف عند كل GATE وانتظر موافقتي.

## ما يحتاج قرارك قبل البدء
- **ADR-000:** بناء مخصص كامل، أم الخيار الوسط (منصة تجارية خلفية + واجهة مخصصة).
- الاسم النهائي بعد بحث العلامة التجارية.
- لغات الإطلاق: الثلاث، أم التركية والعربية أولًا.
- تصنيف خلطات العسل قانونيًا (غذاء أم مكمل غذائي) مع مستشار، قبل تصنيعها.
- مزود الدفع وشركة الشحن ومزود الفاتورة الإلكترونية.
