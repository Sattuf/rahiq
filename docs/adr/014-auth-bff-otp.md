# ADR-014: المصادقة: رمز لمرة واحدة للزبائن، وكلمة مرور + TOTP للإدارة، ونمط BFF

- **الحالة:** مقبول

## القرار
- **الزبون:** دخول بلا كلمة مرور، برمز من 6 أرقام يُرسل بالبريد (security.md §1: "أسهل لزبائن المتجر"). الرمز مخزن كـ hash، صالح 10 دقائق، 5 محاولات، ورسالة موحدة لا تكشف وجود البريد.
- **الإدارة:** بريد + كلمة مرور (PasswordHasher من ASP.NET Core Identity، 10 أحرف على الأقل) + **TOTP إلزامي** (RFC 6238). قفل متصاعد بعد المحاولات الفاشلة.
- **الرموز:** JWT قصير (15 دقيقة) + Refresh token مُدوّر بعائلة (family): إعادة استخدام رمز قديم تُبطل العائلة كلها.
- **BFF:** Next.js يحفظ الرموز في كوكي httpOnly مشفّر (Secure، SameSite=Lax). المتصفح لا يرى أي رمز. حماية CSRF بكوكي مزدوج + ترويسة.
- الصلاحيات الدقيقة (`orders.refund`، `prices.edit`...) claims في رمز الموظف، والأدوار الخمسة خرائط ثابتة إلى صلاحيات.

## المرفوض
ASP.NET Core Identity كاملًا بجداوله: ثقيل لحالتنا (لا كلمات مرور للزبائن، ولا تسجيل دخول خارجي في V1). نستعمل منه `PasswordHasher` فقط.
