# ADR-004: PostgreSQL، والمال أعداد صحيحة

- **الحالة:** مقبول (من حزمة الخطة)
- **المصدر:** rahiq-plan/references/decisions-adr.md

- قيود CHECK تحمي المخزون والمجاميع حتى لو أخطأ الكود، `jsonb` للخصائص، `FOR UPDATE` للحجز. المال `bigint` بالقروش، لا `decimal` في الحسابات الوسيطة ولا `double` أبدًا. المرفوض: قاعدة NoSQL (نحتاج معاملات صارمة).
