# ADR-017: رسم الدفع عند الاستلام، وأسطر الطلب "الورقية" للباقات والهدايا

- **الحالة:** مقبول. يوسّع data-model.md §4.

1. **رسم الدفع عند الاستلام** عمود مستقل `cod_fee`، والقيد يصبح `total = subtotal - discount + shipping + cod_fee`. خلطه بالشحن يربك الفاتورة والاسترداد.
2. **الباقة وصندوق الهدايا** يُفككان في الطلب إلى أسطر "ورقية" لكل مكوّن (بـ `group_id` و`group_label_snapshot`)، لأن مكوّناتها قد تختلف في نسبة الضريبة (عسل غذاء، عطر تجميل). سعر الباقة الثابت يُوزع على مكوناتها نسبيًا (الباقي لآخر سطر)، فتبقى الضريبة صحيحة حتى آخر قرش. الواجهة تعرض المجموعة سطرًا واحدًا.
