# ADR-015: العقود تُحفظ كمستند HTML مجمّد ببصمة SHA-256

- **الحالة:** مقبول. يؤجل جزءًا من compliance.md ("نسخة PDF").

## القرار
نموذج المعلومات المسبقة وعقد البيع عن بعد يُولّدان من قوالب لكل لغة ببيانات الطلب الفعلية. **النص الذي يراه الزبون هو نفسه الذي يُحفظ**: الخادم يعيد توليده عند "ادفع"، ويقارن بصمته بالبصمة التي قبلها الزبون، ويرفض إن اختلفت (تغير سعر أو عنوان بعد العرض). المستند المحفوظ HTML مستقل (أنماط مضمنة)، والبصمة في `ordering.orders.contract_doc_hash`.

## لماذا لا PDF الآن
توليد PDF بالعربية (RTL وتشكيل الحروف) على خادم Linux يتطلب خطوطًا ومكتبة تُختبر بعناية. المستند HTML المجمد يحقق الغرض القانوني (المحتوى وبصمته وقت القبول). التحويل إلى PDF لاحقًا لا يغير البصمة المرجعية لأنها بصمة المحتوى المقبول.
