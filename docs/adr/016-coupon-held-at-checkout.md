# ADR-016: استخدام القسيمة يُحجز عند الدفع ويُثبّت عند التأكيد

- **الحالة:** مقبول. يدقق commerce-flows.md §8.

## السياق
الخطة: "الاستخدام يُحتسب عند تأكيد الطلب لا عند الإدخال، مع قفل يمنع تجاوز `max_uses` بالتزامن". لكن الدفع بالبطاقة يحسب الخصم في المبلغ **قبل** التأكيد. لو احتُسب الاستخدام عند التأكيد فقط، قد يدفع الزبون الحادي عشر مبلغًا مخصومًا لقسيمة نفدت.

## القرار
مثل المخزون تمامًا: عند "ادفع" يُحجز استخدام بتحديث ذري (`used_count < max_uses`) داخل نفس المعاملة. فشل الدفع أو انتهاء المهلة يحرره، والتأكيد يثبّته. لا يُحتسب شيء عند مجرد إدخال الكود في السلة. اختبار "30 طلبًا متزامنًا → 10 فقط" يثبت ذلك.
